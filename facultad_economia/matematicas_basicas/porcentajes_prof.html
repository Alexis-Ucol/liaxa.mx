1 FACTOR MULTIPLICATIVO & MGC
Artículo: C = $580, MGC = 30%
MGC = (PV − C) ÷ C  base = Costo
= ($754 − $580) ÷ $580 = 30%
Inverso — hallar C: C = PV ÷ 1.30
= $754 ÷ 1.30 = $580 ✓
⚠ MGC ≠ Margen. Misma ganancia, distinta base.
2 MARGEN BRUTO VS. MGC
Mismo artículo: PV = $754, C = $580
Ganancia = $754 − $580 = $174
Margen = (PV−C) ÷ PV  |  C = PV × (1−Margen)
